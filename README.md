What I Learned

In this assignment I learned how to create a Hamburger Menu using only CSS without JavaScript.

Key Concepts

1. Media Queries

Used to make website responsive
Hide navbar links in mobile
Show hamburger icon

2. Position Absolute

Used to place menu on right side
Menu covers full height

3. :focus Pseudo Class

Used to show menu when button is clicked
No JavaScript required

4. Sibling Selector (+)

Helps to open menu when button is focused
.menu-btn:focus + .mobile-menu

This means:

When menu button is clicked, show mobile menu.

Features
Responsive Navbar
Mobile Hamburger Menu
Right Side Sliding Menu
No JavaScript Used
Pure CSS Implementation
 Output

Desktop -> Normal Navbar
Mobile -> Hamburger Menu -> Click -> Menu opens from right
